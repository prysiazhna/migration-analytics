## Introduction

As a Ukrainian immigrant, I was personally motivated to explore and visualize migration trends to gain a deeper understanding of how recent global events have affected millions of Ukrainians, including myself.
This dashboard presents a visual overview of Ukrainian migration over the past 15 years, with a particular focus on the period that began with the full-scale Russian invasion in 2022.

The project was built using Excel and Tableau, using publicly available datasets from trusted international sources. It offers insights into net migration trends, international refugee distribution, and country-specific statistics.

## 📊 Dashboard Highlights

### 🌍 Top Countries Hosting Ukrainian Refugees — Map Chart  
An interactive map showing where the majority of Ukrainian refugees relocated, with color-coded regions to highlight concentration.

### 🍰 Refugee Distribution — Pie Chart  
A pie chart visualizing the top 15 host countries by refugee count, with an additional **"Others"** category representing the combined total of all remaining countries. The chart reflects 100% of total refugee distribution.

### 📈 Net Migration Trends — Line Graph  
Side-by-side line graphs showing the changes in net migration before and after 2022, helping to compare long-term and war-driven movement.

**Net migration** refers to the difference between the number of people entering and leaving a country. A negative value means more people left the country than entered it.

### 🔽 Drop-down Filters  
- Country-level filtering to display migration metrics per selected country  
- Dynamic KPIs such as total refugee count and country rank
